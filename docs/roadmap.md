# Roadmap

Priorities are ordered by security and ecosystem value, not promised dates.

1. Linux Secret Service and Windows Credential Manager adapters.
2. A constrained Provider Adapter interface for additional Responses-compatible models.
3. Configurable DLP rules, organization policies, and pluggable secret scanners.
4. Signed handoff manifests, append-only audit records, and encrypted team sharing.
5. Privacy-preserving Provider cost, latency, cache-hit, and failure-rate metrics.
6. Codex Plugin/MCP integration, a macOS menu-bar UI, and opt-in automation hooks.
7. SBOM generation, signed releases, provenance, reproducible CI, and isolated testing for third-party contributions.

Any automation that sends content or enables writes must preserve the current preview, digest-confirmation, and fail-closed defaults.
